# 📦 Inventory Management System Using SQL

## 📌 Project Overview
The Inventory Management System is a SQL-based project designed to store and manage inventory item details. It helps organize item information and track available quantities.

## 🎯 Project Objective
- Store inventory item details in a structured database.
- Maintain item IDs, names, and quantities.
- Understand database creation and table management using SQL.
- Build practical SQL skills through a real-world use case.

## 🛠️ Tools & Technologies
- SQL
- SQLite Database

## 🗄️ Database Structure
Table Name:`items`

| Column Name | Description |
|---|---|
| `id` | Unique ID for each item |
| `name` | Name of the item |
| `quantity` | Available quantity of the item |

## 📚 SQL Concepts
- Database and table creation
- Primary keys
- Data storage and retrieval
- Inventory quantity management

## 💡 Future Improvements
- Add, update, and delete inventory items.
- Identify low-stock items.
- Track total inventory quantities.
- Generate inventory summary reports.
